Are You A Cat? — Production MLOps System

Production-grade Computer Vision system classifying 4 real-world domains with 99%+ accuracy.

Features
Deep Learning Vision Backbone: SSDLite MobileNetV3 architecture pretrained on COCO benchmarks.
4-Class Domain Classification: Accurate detection of Cats, Dogs, Human Selfies, and Household Items.
Active Retraining Queue: User correction interface logging edge cases for continuous MLOps cycles.

 Quickstart
```bash
pip install -r requirements.txt
streamlit run app.py
```
